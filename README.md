# Color Detection
Welcome to Color Detection Project!
This is my first Machine Learning project, in this project I used teachable machines, a platform that helps to create their ML projects. 
This project is done using Keras Model, a model is an object that groups layers together and that can be trained on data. For Keras model to work, Tensorflow is required as Keras Model is imported from Tensorflow. 
Tensorflow is an open source machine learning and deep learning framework and it provides various tools to process, build and deploy the project.
This project was done on Google Colab. Google Colab is a free cloud-based service that allows you to write and execute Python code directly in your web browser.
